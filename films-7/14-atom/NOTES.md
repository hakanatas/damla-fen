## Bilimsel doğruluk kontrolü
| İfade | Kontrol |
|---|---|
| Democritus ≈ 2400 yıl önce (MÖ 5. yy) | MÖ ≈ 460–370; doğru. "atomos" = bölünemez. |
| Dalton 1803, Thomson 1904, Rutherford 1911, Bohr 1913 | Yaygın kabul gören yıllar (Dalton ilk sunum 1803, yayın 1808; elektron 1897, Thomson modeli 1904). |
| Thomson: artı yüklü küre içinde elektronlar | Doğru ("üzümlü kek" adı kullanılmadı). |
| Rutherford: küçük, artı yüklü çekirdek; çevresi çoğunlukla boşluk | Doğru. |
| Proton +1, nötron yüksüz, elektron −1 | Doğru. |
| Elektron kütlesi ≈ 1/1836 proton | mp/me = 1836,15; doğru. Proton ≈ nötron (nötron %0,14 ağır). |
| Karbon-12: 6p 6n; oksijen-16: 8p 8n; hidrojen-1: 1p 0n | Doğru (en yaygın izotoplar). Hidrojen çekirdeği nötronsuz çizildi. |
| Katmanlardaki elektron sayıları (C: 2,4; O: 2,6; H: 1) | Doğru; bu filmde yalnızca görsel. |
| Stadyum–nohut benzetmesi | Atom çapı ~10⁻¹⁰ m, çekirdek ~10⁻¹⁵–10⁻¹⁴ m → oran 10⁴–10⁵; 100–200 m stadyumda 1–10 mm; nohut uygun. "(çizim ölçekli değildir)" yazıldı. |
| Elektron bulutu yoğunluğu merkezde fazla, dışa doğru azalır | Nitel olarak doğru (tek bir orbital şekli iddia edilmez). |
