## Bilimsel doğruluk
| İfade | Kontrol |
|---|---|
| Sindirim: besinlerin hücrelerin kullanabileceği küçük parçalara ayrılması | Ders kitabı tanımı. |
| Kanal: ağız → yutak → yemek borusu → mide → ince bağırsak → kalın bağırsak → anüs | Doğru. |
| Ağızda kimyasal sindirim başlar (tükürük) | Doğru (karbonhidratlar, tükürük enzimi). Enzim adı verilmedi. |
| Yemek borusu kasılarak lokmayı iter | Doğru (peristaltik hareket; terim verilmedi). |
| Mide kaslı, esnek torba; mide öz suyu | Doğru. |
| İnce bağırsak kanalın en uzun kısmı; sindirim tamamlanır; besinler kana geçer | Doğru. Yağların bir kısmı lenfe geçer; programda lenf olmadığından sadeleştirildi. Uzunluk sayısı bilinçli olarak verilmedi. |
| Kalın bağırsak suyun bir kısmını emer, artıklar anüsten atılır | Doğru. |
| Karaciğer safra üretir; safra yağları küçük damlacıklara ayırır (fiziksel sindirime yardım) | Doğru. Safra kesesi programda yok, çizilmedi. |
| Pankreas ince bağırsağa sindirim enzimleri gönderir | Doğru. |
| Besin karaciğer ve pankreasın içinden geçmez | Doğru (yaygın kavram yanılgısı düzeltildi). |
| Enzim: sindirimi (parçalanmayı) hızlandıran özel madde | Programa uygun tanım. |
| Organ yerleşimi | Karaciğer kişinin sağında (izleyicinin solu), mide solda, pankreas midenin arkasında-altında, kalın bağırsak çerçeve biçiminde. Şema "ölçekli değildir". |
| Sağlık önerileri | Genel, hastalık adı içermeyen öneriler (düzenli ve dengeli beslenme, yavaş yeme, yeterli su, hareket). |
