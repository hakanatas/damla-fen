## Bilimsel doğruluk
| iddia | kontrol |
|---|---|
| Sabit makara ≈ 10 N (10 N yük) | İdeal F = G; gerçek değer biraz fazladır, "yaklaşık" deniyor |
| Makara sistemi ≈ 6 N, tam 5 değil | İdeal 5 N; hareketli makaranın ağırlığı (≈ 1 N) + sürtünme → ≈ 6 N makul |
| Arkadaşın çıkrığı ≈ 4 N | Kol ≈ 3 × mil → ideal ≈ 3,3 N + sürtünme |
| Makara sistemi + çıkrık (kol = 3 × mil) ≈ 2 N | İdeal 10 / 2 / 3 ≈ 1,7 N; sürtünmeyle ≈ 2 N |
| İşten kazanç yok; sürtünmeyle biraz fazla iş | Enerji korunumu; sürtünmede enerjinin bir kısmı ısıya dönüşür |
| Animasyon oranları | M1: yük h ↔ ip h; M2: yük h ↔ ip 2h; M3: tambur ipi r·θ sarar, yük r·θ/2 yükselir, el 3r·θ yol alır |
| Cezeri kitabını 1206'da bitirdi | "Kitâb fî ma'rifat al-hiyal al-handasiyya", 1206 (Artuklu sarayı) |
| Cezeri çiziminde dişli çarklı su yükseltme düzeni | Temsilî çizim olduğu ekranda yazıyor |
| Arşimet burgusu | Geleneksel olarak Arşimet'e atfedilir |
| DNA çift sarmalı (sonraki film tanıtımı) | "(çizim temsilîdir)" notu var |
