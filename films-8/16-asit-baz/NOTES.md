## Bilimsel doğruluk
| iddia | kontrol |
|---|---|
| Asit suda H⁺, baz OH⁻ verir | Arrhenius tanımı; 8. sınıf düzeyi. NH₃ suyla tepkimeyle OH⁻ oluşturur (ayrıntıya girilmedi) |
| tuz ruhu = HCl, kezzap = HNO₃, akü asidi = H₂SO₄, sirke = CH₃COOH (asetik asit), gazoz = H₂CO₃ | ✓ (sirke ve gazoz bu asitleri içeren çözeltiler) |
| sud kostik NaOH, potas kostik KOH, sönmüş kireç Ca(OH)₂, amonyak NH₃ | ✓ |
| Sulu çözeltileri elektrik iletir; ikisi de aşındırıcı olabilir | ✓ (derişik olanlar aşındırıcı; "olabilir") |
| Asitler bazı metallerle (ör. demir, çinko) ve mermerle (CaCO₃) tepkimeye girer | ✓ ("bazı" — bakır, altın gibi metaller seyreltik asitle tepkimeye girmez) |
| Bazlar cam, porselen, seramik ve yağlarla etkileşir | Program ifadesi ("genellikle"); yağlarla sabunlaşma ✓ |
| Asit + baz → tuz + su | Nötrleşme ✓ |
| Turnusol: mavi → asitte kırmızı; kırmızı → bazda mavi; nötrde değişmez | ✓ |
| Mor lahana: pH ≈ 2 kırmızı, ≈ 3 pembe, ≈ 6,5–7 mor, ≈ 8,3 mavi, ≈ 10 mavi-yeşil/yeşil, ≥ 12 sarı-yeşil | ✓ (antosiyanin renkleri; tonlar yaklaşık, çizim suluboya) |
| Fenolftalein: asitte ve nötrde renksiz, bazda pembe | ✓ (dönüm ≈ pH 8,2–10) |
| Metil oranj: asitte kırmızı, nötr ve bazda sarı | ✓ (dönüm ≈ pH 3,1–4,4; zayıf asitlerde turuncu görünebilir — sahne 9'daki "zayıf olanlarda renk az değişebilir" uyarısı bununla tutarlı) |
| Süt ≈ pH 6,5–6,8 → mor lahana ile mor | ✓ "nötre çok yakın" |
| Çamaşır suyu mor lahana testine konulmadı | Bilinçli: hipoklorit ayıracı ağartır, yanıltıcı olur |
| Amonyaklı cam temizleyici bazik | ✓ (pH ≈ 10–11) |
