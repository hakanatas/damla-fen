| Saf su 7 | ✓ (25 °C) |
| Karbonatlı su (sodyum bikarbonat çözeltisi) ≈ 8,3 | ✓ |
| Sabunlu su ≈ 10 | ✓ (9–10) |
| Çamaşır suyu ≈ 12,5 | ✓ (12–13) |
| Şampuan pH 5,5, içme suyu pH 7,4 | Gerçekçi etiket değerleri (şişe suları 6,5–8,5 arasında) |
| pH < 7 asit, 7 nötr, > 7 baz; 0'a yaklaştıkça asitlik artar | ✓ (25 °C, sulu çözelti) |
| Cetvel renkleri | Mor lahana tonları (ekranda not: "renkler: mor lahana suyunun yaklaşık tonları") — evrensel indikatör kullanılmadı, programda yok |
| Sirke + mermer / yumurta kabuğu (CaCO₃) → kabarcık (CO₂) | ✓ hemen görülür |
| Mermer kütle kaybı 0,8 g / 3 gün | Temsilî, "örnek veri" etiketli; 10 g mermer, fazla sirke için makul büyüklük |
| Demir çivi + sirke: yüzey aşınır, matlaşır, az kabarcık (H₂) | ✓ (yavaş; günler içinde) |
| Bazlar cam/porselen/seramiği aşındırır; bulaşık makinesinde bardak matlaşması | ✓ (bazik deterjan + yumuşak su camda korozyon) |
| Asitler metal kapta, güçlü bazlar camda uzun süre saklanmaz | ✓ (derişik NaOH polietilen kapta saklanır) |
| Çamaşır suyu + tuz ruhu → zehirli gaz | ✓ (klor gazı) |
