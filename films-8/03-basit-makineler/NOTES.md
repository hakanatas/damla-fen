## Bilimsel doğruluk
| iddia | kontrol |
|---|---|
| Eşit kollar → eşit kuvvetler dengede | Tork dengesi; çizimde kollar 360/360 px |
| Kuvvet kolu 2 kat → 20 N yeter | Yük 600 px, destek 840 px, kuvvet 1320 px noktasında: kollar 240/480 (tam 1:2); ok boyları 168/84 px |
| Yük 10 cm ↔ uç 20 cm | Tahta destek etrafında gerçekten döndürülür (sinφ = 0,25); dikey yer değiştirmeler 60/120 px (1:2) |
| Yük ortada → hep kuvvetten kazanç; kuvvet ortada → hep yoldan kazanç; destek ortada → kollara bağlı | Standart sınıflama; örnekler: tahterevalli, makas, pense / el arabası, ceviz kıracağı / cımbız, maşa, olta |
| Sabit makara: F = yük, yön değişir | İdeal; ip ucu h iner, yük h çıkar |
| Hareketli makara: 2 ip × 20 N; ip 2h çekilir | İp boyu korunumu ile animasyon (yük 60 px, el 120 px) |
| Makara sistemi (1 sabit + 1 hareketli): yön değişir, F = yük/2 | Tüm ip parçaları düşey; el 2h, yük h |
| Eğik düzlem 30°, yol 2h → 20 N | Sürtünmesiz: F = G·h/L oranı (formül ekranda yok); çizim açısı asin(0,5) |
| Vida = sarılmış eğik düzlem | Klasik kâğıt-üçgen gösterimi |
| Çıkrık: kol = 4 × mil yarıçapı → 10 N; kova r·Δθ kadar yükselir | Animasyonda kova yükselişi mil yarıçapıyla, el yolu kol yarıçapıyla |
| 24 diş / 12 diş: 1 tur → 2 tur, zıt yön | Çarklar diş-boşluk eşleşmesiyle döner (θ₂ = π − 2θ₁) |
| Düz kayış aynı yön, çapraz kayış zıt yön | Eşit kasnaklar; çapraz kayış iç teğetleri hesaplanarak çizildi |
| Bisiklet: büyük aynakol dişlisinden küçük arka dişliye → yoldan (hız) kazanç | 20/9 diş oranıyla dönüyor |
| "Sürtünme ve makara ağırlığı ihmal edildi" | Makara ve rampa ekranlarında not var |

## Bilinen sorunlar / notlar
- Programdaki "bir enerji türünü başka bir enerji türüne dönüştürme" grubu ayrı bir sütun olarak işlenmedi; film yalnızca enerji korunumu vurgusunu verir (bu gruplama basit makinelerde fiziksel olarak tartışmalı olduğu için bilinçli tercih).
- Bisiklet sahnesinde "pedal + aynakol" çağrı çizgisi uzun ve çerçeveyi kesiyor (okunuyor).
- Kaydet sahnesinde Damla, 01-gunes referansındaki gibi sayfanın sağ alt köşesinde, alt şeride hafifçe taşar.
