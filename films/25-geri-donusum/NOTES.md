# 25 · Atıklarımızı Tanıyalım — FB.5.7.1

**Çıktı:** Evsel atıklarda geri dönüştürülebilen ve dönüştürülemeyen maddeleri sınıflandırabilme
**Süre:** ≈ 208,7 sn (sessiz sürüm, `timing.js`)
**Film yardımcıları:** `props.js` → `window.W7` (evsel atık çizimleri, Sıfır Atık kutuları, geri dönüşüm sembolü, mutfak zemini; 26 ve 27. filmlerde aynı dosyanın kopyası vardır)

## Sahne planı
| # | Sahne | Beat'ler | Öğrettiği |
|---|---|---|---|
| 1 | Mutfak | title → bag | Merak: "Torbadakilerin hepsi gerçekten çöp mü?" |
| 2 | Güvenlik | stop → spill | Eldiven; kırık cam/porselen yetişkin toplar; pil açılmaz. Torba dökülür: **evsel atık** tanımı, **katı atıklar** |
| 3 | Nitelikler | paper → organic | Malzemeye göre nitelik tablosu (kâğıt-karton, cam, metal, plastik, besin artığı) |
| 4 | Sembol | symbol → define | Ambalajdaki **geri dönüşüm sembolü**; döngü: toplanır → ayrıştırılır/işlenir → ham madde → yeni ürün; tanım |
| 5 | Ayrıştır | sort → compost | Çalışma kâğıdı: geri dönüştürülebilen / dönüştürülemeyen sütunları; besin artıkları → kompost |
| 6 | Kutular | group → colors | Malzemeye göre gruplama + Sıfır Atık kutu renkleriyle etiketleme |
| 7 | Özel kutular | battery → textile | Atık pil kutusu, atık yağ kumbarası, tekstil kutusu; "çöpe değil / lavaboya değil" |
| 8 | Kaydet | record → value | Gözlem defteri özeti; Tanımla → Ayrıştır → Grupla → Etiketle = Sınıflandır; değer kartı |
| 9 | Sıra sende | task → end | Evdeki atıkları etiketleme görevi; sonraki film: "Geri Dönüşüm Neden Önemli?"; bitiş kartı |

## Bilimsel doğruluk kontrolü
| İfade | Not |
|---|---|
| Sıfır Atık kutu renkleri: mavi kâğıt-karton, sarı plastik, yeşil cam, gri metal, kahverengi organik (biyobozunur), siyah diğer | Sıfır Atık Yönetmeliği (2019) standart renkleri |
| Kirli peçete, ıslak mendil, kırık porselen geri dönüştürülemez | Kirlenmiş kâğıt ve karışık lifli mendiller geri dönüşüme uygun değildir; porselen/seramik camla aynı işlemden geçemez → "porselen cama atılmaz" |
| Besin artıkları geri dönüşüm kutusuna atılmaz; kompostla toprağa geri kazandırılabilir | "Geri dönüşüm" değil "geri kazanım/kompost" ifadesi bilinçli seçildi |
| Plastik doğada çok uzun sürede parçalanır | Nitel ifade; sayı verilmedi |
| Pillerdeki zararlı maddeler toprağa ve suya karışabilir | Pil ayrı kutuda toplanır |
| Atık yağ lavaboya dökülmez, soğuyunca şişeyle kumbaraya verilir | Belediyelerin atık yağ uygulaması |
| Temiz kumaş/tekstil ayrı toplanır | Tekstil toplama kutuları |
| Geri dönüşüm tanımı: atık → işlenir → ham madde → yeni ürün | Yeniden kullanım/ileri dönüşümden ayrı tutuldu |

## Güvenlik
Kırmızı "⚠ GÜVENLİK" kartı: eldiven; kırık cam ve porselen yalnızca bir yetişkin tarafından toplanır; pil açılmaz, ısırılmaz, ateşe atılmaz. Defter özetinde tekrar edilir.
